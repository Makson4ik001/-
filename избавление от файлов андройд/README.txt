ЗАГЛУШКИ ДЛЯ ФЛЕШКИ: ЧТОБЫ ANDROID НЕ СОЗДАВАЛ ПАПКИ
=====================================================

Что делают скрипты
------------------
В корне флешки удаляют пустые папки Alarms, DCIM, Music, Android, LOST.DIR и т.д.
и создают на их месте скрытые пустые файлы с теми же именами. Android не может
создать папку, если файл с таким именем уже есть.
Папки, в которых есть ваши файлы, не трогаются (в выводе будет "ПРОПУСК").
Запускать достаточно один раз для каждой флешки. После форматирования - заново.

Список имён можно поменять в строке NAMES (Mac) или в строке for %%n in (...) (Windows).


MAC  (android_stubs_mac.sh)
---------------------------
1. Подключите флешку. Узнать её путь:
       ls /Volumes
   Путь будет вида /Volumes/ИМЯ, например /Volumes/Romanov_new

2. Откройте Терминал (Cmd+Пробел -> "Терминал").

3. Вариант А - путь при запуске (редактировать скрипт не нужно):
       bash ~/Downloads/android_stubs_mac.sh /Volumes/Romanov_new

   Вариант Б - путь внутри скрипта:
   откройте скрипт в редакторе кода или командой
       nano ~/Downloads/android_stubs_mac.sh
   и замените [ПУТЬ_К_ФЛЕШКЕ] целиком, вместе со скобками:
       DEFAULT_VOL="/Volumes/Romanov_new"
   (в nano: сохранить Ctrl+O, Enter; выйти Ctrl+X)
   Потом запуск без аргумента:
       bash ~/Downloads/android_stubs_mac.sh

   Не правьте скрипт в TextEdit: он может заменить кавычки на "ёлочки", и скрипт сломается.

   Если имя флешки содержит пробелы, берите путь в кавычки:
       bash ~/Downloads/android_stubs_mac.sh "/Volumes/My USB"

   Если macOS спросит доступ Терминала к съёмному носителю - нажмите "Разрешить".

Показать/спрятать скрытые файлы в Finder: Cmd+Shift+. (точка)


WINDOWS  (android_stubs_windows.bat)
------------------------------------
1. Подключите флешку и посмотрите её букву в "Этот компьютер", например E:

2. Вариант А - двойной клик:
   нажмите на файл правой кнопкой -> "Изменить" (откроется Блокнот),
   замените [БУКВА_ФЛЕШКИ] целиком, вместе со скобками:
       set "DEFAULT_VOL=E:"
   сохраните и запустите файл двойным кликом.

   Вариант Б - из командной строки (Win+R -> cmd -> Enter):
       cd %USERPROFILE%\Downloads
       android_stubs_windows.bat E:

Показать/спрятать скрытые файлы в Проводнике:
   Windows 11: "Вид" -> "Показать" -> "Скрытые элементы"
   Windows 10: вкладка "Вид" -> галочка "Скрытые элементы"


КАК ВЕРНУТЬ ВСЁ ОБРАТНО
-----------------------
Просто удалите скрытые файлы-заглушки с флешки (включите показ скрытых файлов).
Android снова начнёт создавать папки.
